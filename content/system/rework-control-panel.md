# Rework Control Panel (v2)

This page governs the rebuild. If something conflicts with this, this wins until explicitly updated.

---

## A) Non-negotiables
- v1 stays intact during the rebuild.
- v2 is built in parallel and only cut over at the end.
- **Library can be big.** Mirror + Third Layer must stay clean.
- Retrieval must stay fast (avoid v7.1 monolith drift).

---

## B) Canonical vocabulary
- **Library:** durable knowledge and receipts. Can be grand.
- **Mirror Template:** publish-safe schema to generate a pasteable “session bootloader.”
- **Mirror Instance:** live daily state; paste-only/offsite (unless explicitly chosen otherwise).
- **Third Layer:** lived projects and formation, made real by receipts.

---

## C) Status taxonomy (page maturity)
Use these frontmatter values over time:

- `status: canonical` — stable doctrine
- `status: working` — active hypothesis / in-progress
- `status: raw` — dump / legacy extract
- `status: receipt` — field test / milestone / evidence

---

## D) Structural primitives (must exist in v2)
- Backlinks: **Referenced by** (computed from `connected:` graph)
- Tags: `/tags/` taxonomy + navbar link
- System hubs: System / Mirror Template / Third Layer Rules
- Codex Evolution map: lineage + renames + drift traps

---

## E) Ingestion rules (avoid sludge)
- Store raw sources under History (evidence).
- Extract nodes into proper pages with tags and connections.
- Prefer: **one strong page** + backlinks, over duplicates.

---

## F) Open decisions (only blockers)
- Mirror Instance: public or paste-only (default paste-only).
- Third Layer UI: cards vs logs vs board (default: cards + receipts).
- Automate a “most referenced pages” index (optional).
