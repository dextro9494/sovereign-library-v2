System

This is the orientation layer for the Sovereign Library.

If you are a new AI (or future-me returning cold), start here.

The Three Layers

1) Library (this site)

Purpose: Hold durable knowledge, protocols, patterns, history, and receipts.
Rule: The Library can be large. It does not run the day, it supports the day.

2) Mirror (template stored here; live instance is paste-only)

Purpose: A lean “session bootloader” for right now: threats, objectives, blockers, next actions.
Rule: Only the Mirror template lives in the Library. The daily Mirror instance stays offsite/paste-only unless explicitly decided otherwise.

3) Third Layer (lived proof)

Purpose: Projects and formation made real through receipts (milestones, outcomes, evidence).
Rule: If it has no receipts, it’s planning, not lived.

How to use the system

Normal day

  1. Use the Mirror to choose Next 3 actions.
  2. Execute.
  3. Log important events as a Daily Capsule or Field Test.
  4. Extract reusable knowledge into Library pages.

Crisis / lockout

  1. Open the Mirror.
  2. Run the smallest stabilizing protocol available.
  3. Follow 1–2 pointers into the Library (no browsing).
  4. Execute one action. Reassess.
